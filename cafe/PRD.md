# PRD: 브루잉로드 동네 카페 소개 페이지

## 1. 한 줄 요약
처음 오는 손님이 휴대폰으로 가게를 검색했을 때, **메뉴·영업시간·위치를 바로 확인하고 전화하거나 지도를 열어 찾아올 수 있는** 한 장짜리 소개 페이지.

## 2. 배경과 목적
- 작은 카페 사장이 SNS(인스타그램 등)로 가게를 알리고 있다. 관심이 생긴 사람은 가게 이름을 검색해 들어온다.
- 이때 메뉴, 영업시간, 위치가 한눈에 안 보이면 손님은 그냥 나가 버린다.
- 이 페이지의 목적은 **"처음 온 손님이 헤매지 않고 가게까지 찾아오게 하는 것"** 이다.

## 3. 사용자
| 구분 | 설명 |
|---|---|
| 페이지를 만드는/쓰는 사람 | SNS로 가게를 알리고 싶은 작은 카페 사장. 코드를 모르므로 파일 하나로 끝나야 하고, 내용 수정이 쉬워야 한다. |
| 페이지를 보는 사람 | 가게를 처음 알게 된 손님. 휴대폰으로 검색해 들어온다. |

## 4. 사용 상황
- **언제:** 손님이 가게 이름을 검색하거나 SNS 링크를 눌러 들어올 때
- **어디서:** 휴대폰 (세로 화면 기준)
- **원하는 것:** 스크롤을 많이 하지 않고 "뭘 파는지 / 지금 가도 되는지 / 어디인지"를 알고 바로 행동(전화·길찾기)

## 5. 목표와 성공 기준
- 첫 화면(스크롤 전)에서 가게 이름·한 줄 소개와 **전화 / 지도 보기 버튼**이 보인다.
- 메뉴, 영업시간, 위치는 스크롤 몇 번 안에 모두 확인된다.
- 휴대폰에서 버튼 한 번으로 전화 앱 또는 지도가 열린다.
- 가로 스크롤 없이 휴대폰 화면 폭에 맞게 보인다.

### 연락처

## 7. 기능 요구사항

### 필수 (이 다섯 가지는 반드시 있어야 한다)
| # | 기능 | 설명 | 완료 기준 |
|---|---|---|---|
| F1 | 메뉴 | 메뉴 이름과 가격을 목록으로 보여준다. | 3개 메뉴와 가격이 읽기 쉽게 표시된다. |
| F2 | 영업시간 | 월~일 요일별 영업시간을 표로 보여주고, 월요일 휴무를 표시한다. | 요일별 표로 보이고, 휴무일이 눈에 띄게 구분된다. |
| F3 | 위치 안내 | 주소와 "걸포북변역에서 도보 5분" 안내를 보여준다. | 주소와 역 기준 안내가 함께 보인다. |
| F4 | 전화 걸기 버튼 | 누르면 휴대폰 전화 앱이 열리고 031-000-0000이 입력된다. | 휴대폰에서 한 번 눌러 통화 화면으로 넘어간다. |
| F5 | 지도 보기 버튼 | 누르면 지도 앱/웹이 열려 가게 위치를 보여준다. | 한 번 눌러 지도에서 가게 위치가 열린다. |

## 8. 화면 구성 (위에서 아래 순서)
1. **첫 화면:** 가게 이름 + 한 줄 소개 + `전화하기` `지도 보기` 버튼
2. **가게 소개:** 직접 로스팅, 2019년 오픈
3. **메뉴**
4. **공간 안내**
5. **영업시간**
6. **위치 안내** + `지도 보기` 버튼
7. **하단:** 연락처(전화, 인스타그램)

> 전화/지도 버튼은 첫 화면과 하단에서 다시 나와, 어디서 읽다가도 바로 누를 수 있게 한다.

## 9. 디자인 방향
- **톤:** 우드톤 (따뜻한 갈색·베이지·크림 계열, 차분하고 아늑한 느낌)
- **모바일 우선:** 휴대폰 세로 화면을 기준으로 설계하고, PC에서도 깨지지 않게 한다.
- **글자/버튼:** 손가락으로 누르기 쉬운 큰 버튼, 읽기 편한 글자 크기
- **이미지:** 사진 자료가 아직 없으므로 사진 없이도 완성도가 나오도록 색과 글자 중심으로 구성한다. (사진은 나중에 추가 가능)

## 10. 기술 조건
- **HTML, CSS, JS를 하나의 파일(`index.html`)에 모두 작성한다.** (별도 파일·빌드·서버 없이 열면 동작)
- 외부 라이브러리나 서버 없이 동작한다.
- 전화 버튼은 `tel:` 링크, 지도 버튼은 지도 서비스 링크로 연결한다.
- 사장이 직접 수정할 수 있도록 메뉴·시간·연락처 같은 내용은 찾기 쉬운 곳에 모아 둔다.

## 11. 이번 범위에서 하지 않는 것
- 주문·결제·예약 기능
- 회원가입, 로그인, 후기 작성
- 별도 서버, 데이터베이스, 관리자 화면
- 여러 페이지로 나누기 (한 페이지로 끝낸다)

## 12. 정리한 사항 (사장 확인 후 정한 것)
1. **주소:** 받은 자료의 "설포동"은 오타로 보고 **걸포동**(걸포북변역이 있는 동네)으로 고쳤다. 상세 주소가 없으므로 지도 버튼은 "걸포북변역" 위치를 검색해 여는 방식으로 연결한다.
2. **전화번호:** 031-000-0000은 연습용 번호이므로 그대로 쓴다.
3. **평일 범위:** 월요일이 휴무이므로 평일 영업은 화~금으로 해석한다. 화면에서는 "평일/주말"로 묶지 않고 요일별로 한 줄씩 보여준다.
4. **지도 서비스:** 별도 지정이 없어 누구나 열 수 있는 지도 검색 링크를 쓴다.
5. **사진:** 자료가 없으므로 이번에는 사진 없이 만든다. (나중에 추가 가능)
